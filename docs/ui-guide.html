Design tokens

Every color, size, radius and shadow is a CSS variable in the :root block of styles.css. Change one and every page updates. The dark theme overrides the same names under [data-theme="dark"], so these swatches change when you switch theme.

How to change the look

  1. Open public/styles.css and find the :root block at the top.
  2. Change a token, for example the brand color. Keep white text readable: check the new color has at least 4.5:1 contrast with white.
  3. Update the dark theme in the [data-theme="dark"] block if the new color needs a lighter version there.
  4. Never hardcode a color in a component rule. Add a new token instead, so dark mode and future changes keep working.
:root {
  --primary: #1f6fd1;        /* buttons, active nav, switches */
  --primary-hover: #1a5fb4;
  --accent-text: #1a5fb4;    /* links and icons on white */
  --r-lg: 0.75rem;           /* card corners */
  --control-h: 2.5rem;       /* button and input height */
}
